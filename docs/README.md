## 📄 Planning Documents

### [Competitor Analysis](competitor-analysis.md)
**What it covers**:
- Direct competitors (ToyTrader, ToySwap, YoungPlanet)
- Adjacent competitors (Chợ Tốt, Facebook Marketplace)
- Vietnam market analysis
- Feature comparison matrix
- Competitive positioning

**Why it matters**: Understand the competitive landscape and our differentiation strategy.

**Key takeaway**: No toy swap app has traction in Vietnam. Chợ Tốt dominates secondhand but lacks toy-specific features.

---

### [Friction Analysis](friction-analysis.md)
**What it covers**:
- Edge cases that will break the system
- User pain points & objections
- Trust & safety concerns
- Post-match negotiation problems
- Supply/demand imbalances

**Why it matters**: Anticipate problems before they occur. Design solutions proactively.

**Key takeaway**: Value perception was the biggest risk. We solved it by removing value entirely (preference-based matching).

---

### [Valueless Model Analysis](valueless-model-analysis.md)
**What it covers**:
- Why we chose preference-based matching (no value calculations)
- How the Tinder-style flow works
- Remaining friction points (post-match negotiation)
- Simplified MVP flow
- Validation tests

**Why it matters**: This is the core innovation. Removing value eliminates trust issues.

**Key takeaway**: Swapping is about preferences, not math. If it feels unfair, swipe left.

---

### [Elevator Pitch](elevator-pitch.md)
**What it covers**:
- Validation messaging for different platforms (Facebook, Reddit, Instagram)
- Google Form survey questions
- 3 pain point angles:
  - Partner tension (budget conflicts)
  - Sell-buy inefficiency (time wasters)
  - Language barrier (expat-local bridge)
- Objection handling scripts
- Success metrics for validation

**Why it matters**: Test demand BEFORE building. Get 100+ survey responses to validate.

**Key takeaway**: Start with "Partner Tension" angle (most relatable). Target 50%+ "Very interested" rate.
