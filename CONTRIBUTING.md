# Contributing to ToySwap

Thank you for your interest in contributing to ToySwap! 🎉

---

## 📋 Project Status

**Current Phase**: Validation & Planning

We are currently in the **pre-launch validation phase**. The project is not yet accepting code contributions, but we welcome:

- ✅ Feedback on the concept
- ✅ Survey responses (validation)
- ✅ Suggestions for features
- ✅ Bug reports (once development starts)

---

## 🚀 How to Contribute Now

### 1. Validation Feedback

Help us validate the concept:
- Fill out the [validation survey](link-TBD)
- Share feedback in [GitHub Discussions](link-TBD)
- Test messaging with your parent friends

### 2. Documentation Improvements

Found a typo or want to improve docs?
1. Fork the repository
2. Create a branch: `git checkout -b docs/fix-typo`
3. Make your changes
4. Commit: `git commit -m "docs: fix typo in implementation plan"`
5. Push and create a Pull Request

### 3. Feature Suggestions

Have ideas for MVP features?
1. Open a [GitHub Issue](link-TBD)
2. Use the "Feature Request" template
3. Explain the problem it solves
4. Describe the proposed solution

## 🛠️ Development Contributions (Coming Soon)

Once we complete validation and start development:

### Prerequisites
- Node.js 18+
- React Native experience
- Familiarity with Supabase

### Setup (TBD)
```bash
# Clone the repo
git clone https://github.com/[your-username]/toy-swap.git

# Install dependencies
cd toy-swap/app
npm install

# Set up environment variables
cp .env.example .env
# Edit .env with your Supabase credentials

# Start development server
npm start
```

### Code Style
- We use ESLint + Prettier
- TypeScript for type safety
- Follow React Native best practices
- Write meaningful commit messages

### Commit Message Format
```
type(scope): subject

body (optional)

footer (optional)
```

**Types:**
- `feat`: New feature
- `fix`: Bug fix
- `docs`: Documentation changes
- `style`: Code style changes (formatting)
- `refactor`: Code refactoring
- `test`: Adding tests
- `chore`: Maintenance tasks

**Examples:**
```
feat(auth): add phone number verification
fix(swipe): resolve match detection bug
docs(readme): update installation instructions
```

## 🔍 Code Review Process

1. All code changes require a Pull Request
2. At least 1 approval required before merge
3. CI checks must pass (tests, linting)
4. Keep PRs small and focused (< 500 lines)

---

## 🐛 Bug Reports

Found a bug? Open an issue with:
- Clear description of the problem
- Steps to reproduce
- Expected vs. actual behavior
- Screenshots (if applicable)
- Device/OS information
